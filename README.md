# 動画フレーム切り出し

Windows用のシンプルな動画フレーム保存ツールです。音声は再生しません。

## 起動

Pythonをインストールし、初回のみこのフォルダーで次を実行します。

```powershell
python -m pip install -r requirements.txt
```

`起動.bat` をダブルクリックしてください。`python app.py` でも起動できます。

## 操作

1. 「動画を開く」で動画ファイルを選択します。
2. 必要に応じて保存先の「変更」で出力フォルダーを選びます。
3. 左右キーで1フレームずつ移動し、ShiftまたはEnterで表示中のフレームを保存します。

| 操作 | キー |
| --- | --- |
| 1フレーム戻る / 進む | ← / → |
| 表示中のフレームをPNG保存 | Shift（左右いずれも可）/ Enter |
| 直前に保存した画像を取り消す（削除） | Ctrl+Z |
| 再生 / 一時停止 | Space |
| 動画を開く | Ctrl+O |

スライダーで大きく移動できます。フレーム移動や保存をすると再生は一時停止します。
Shift / Enterは押すたびに1枚保存します。長押しによる連続保存は行いません。
保存した画像は画面下部にフレーム番号順でプレビュー（サムネイル画像・フレーム数）として一覧表示され、クリックするとそのフレームへ移動できます。Ctrl+Zで直前に保存した画像の取り消し（ファイルの削除）ができます。

保存先の初期値は動画と同じ場所の「動画名_frames」フォルダーです。一度指定した保存先はアプリを終了するまで次の動画でも使用します。
保存先フォルダーは保存時に自動作成します。

画像は元動画の解像度のPNGです。画面表示用の縮小は保存画像に影響しません。
ファイル名は `動画名_frame_00000001.png`（先頭フレームが1）です。
同名ファイルがある場合は `_1`、`_2` と付けて上書きを防ぎます。
時刻表示はフレーム番号と動画のFPSから計算した目安で、可変フレームレート動画の実際の時刻とは異なることがあります。
対応形式はOpenCVがデコードできるローカル動画です。コーデックや破損状態によって読み込めない場合があります。
プレビュー再生は処理速度によって実際の動画より遅くなる場合があります。
